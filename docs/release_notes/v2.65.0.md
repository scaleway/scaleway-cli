## Edge services

### WAF rules exclusion

The Edge services pipeline documentation now covers the WAF rules exclusion feature, making `scw edge-services` help output reflect what the API supports.

## Key Manager

### Protection level visibility

`scw key-manager key` now exposes the `protection-level` argument (`software` or `hsm`) at creation and shows it in outputs, so you can see at a glance where your key material lives:

```sh
scw key-manager key create name=prod-key protection-level=hsm
```

## MongoDB

### Endpoint create and delete

MongoDB Database Instances now expose dedicated endpoint commands, so you can attach a private network to an instance or remove its endpoint without recreating it:

```sh
scw mongodb endpoint create <instance-id> endpoint.private-network.private-network-id=<pn-id>
scw mongodb endpoint delete <endpoint-id>
```
