## Highlights

- **Plugin support** — `scw foo` now runs an external `scw-foo` executable found on your `PATH`, the same way `git foo` runs `git-foo`. [#6422](https://github.com/scaleway/scaleway-cli/pull/6422)
- **k8s connect opens k9s** — `scw k8s cluster connect` drops you straight into k9s (or any tool via `--template`). [#6375](https://github.com/scaleway/scaleway-cli/pull/6375)
- **Global no-headers flag** — strip the header row from human-readable table output. [#6414](https://github.com/scaleway/scaleway-cli/pull/6414)
- **Cockpit Alloy config** — generate ready-to-paste Alloy snippets for metrics, logs and traces. [#5638](https://github.com/scaleway/scaleway-cli/pull/5638)
- **Bare metal network boot** — boot bare metal servers from a network service instead of a local disk. [#6416](https://github.com/scaleway/scaleway-cli/pull/6416)

## Breaking changes and migrations

- **mongodb**: the CLI namespace migrated from `v1alpha1` to the **stable v1** API. Update scripts that rely on v1alpha1 command names or field casing. [#6298](https://github.com/scaleway/scaleway-cli/pull/6298)
- **search**: the `datalab` resource type was renamed from `ddl_datalab` — update scripts and filters that pass the old value. [#6371](https://github.com/scaleway/scaleway-cli/pull/6371)

## Core

- **Plugins**: external `scw-*` executables on your `PATH` are now discovered and run, letting you extend the CLI without forking it. Put an executable named `scw-<name>` (e.g. `scw-backup`) on your `PATH`, then call `scw backup ...` — arguments are passed through unchanged and the plugin's exit code is propagated. Dispatch happens before built-in commands are resolved, so avoid naming a plugin after an existing command. [#6422](https://github.com/scaleway/scaleway-cli/pull/6422)
- **Global no-headers flag**: new global `-H/--no-headers` flag that removes the header row from human-readable (table) output — handy when piping command output into scripts or `awk` that would otherwise trip over column names:

  ```sh
  scw instance server list -H
  ```

  [#6414](https://github.com/scaleway/scaleway-cli/pull/6414)
- **SRN integration**: Message Queue (`messageq`) and Search DB deployment-creation commands expose the `volume.deployment-id` field, so automation can pass canonical Scaleway Resource Names (SRNs) end-to-end instead of raw UUIDs. [#6435](https://github.com/scaleway/scaleway-cli/pull/6435)

## Audit trail

Dedicated-pool events now show up in your trail: audit trails report the `instance_dedicated_pool` resource type.

## Baremetal

### Network boot

Servers can now boot from the network. Connect your boot server by setting `network-boot-url`, and control whether it applies at every reboot or only once with `network-boot-persistent`:

```sh
scw baremetal server create ... network-boot-url=https://your-boot-server.example.com
```

## Block

### New Milan zones

Block volumes support the new **`it-mil-1`, `it-mil-2`, `it-mil-3`** zones. Specify them with `zone=` or set one as your default zone.

## Cockpit

### Alloy config snippets

Added Alloy as a new output format for `scw cockpit config get`, so you get a ready-to-paste snippet for any data source — optionally with a token baked in:

```sh
scw cockpit config get <project-id> type=alloy generate-token=true
```

## Domain

### Contact list filters

`scw domain contact list` accepts filters and an `order-by` argument, so you can find contacts by attribute instead of client-side filtering.

## IAM

### Policy deny rules

IAM policy endpoints support the `rules.deny` field — the building block for **explicit-deny** policies (deny rules take precedence over allows).

## IPAM

### Serverless Job resource type

IPAM IP list filters now include the `serverless_job` resource type, so you can find IPs assigned to Serverless Jobs.

## k8s

### Connect to a cluster with k9s

`scw k8s cluster connect` used to only emit a kubeconfig; it now writes it and opens k9s directly. Use `--template` to run a different tool (rendered as a Go template with the kubeconfig path):

```sh
scw k8s cluster connect <cluster-id>
scw k8s cluster connect <cluster-id> template="k9s -c pulses"
```

## Key Manager

### Encrypted import

`ImportKeyMaterial` now accepts an **encrypted** key material payload, letting you transport key material securely instead of in the clear.

## MongoDB

### Stable v1 API

The MongoDB namespace moved from `v1alpha1` to the **stable v1** API (see [Breaking changes](#breaking-changes-and-migrations)).

### Node types scoped by project

`scw mongodb node-type list` now scopes by `project_id`, returning only the node types actually available to your project.

## Redis

### Default version

`scw redis cluster create` now has a sensible default engine version, and `engine=` autocompletion reflects the versions actually available.

## Secret Manager

### Generated names

Empty-out the `name` on `scw secret create` and the CLI generates one for you, so you stop managing unique names in scripts and loops:

```sh
scw secret create name=<generated>
```

## Bug fixes

- **rdb**: completing `scw rdb instance create engine=` suggested **V1 engine names instead of the versioned names the API expects**, and could suggest **disabled** engines. Completion now lists the enabled `engine.Versions` for the region. [#6390](https://github.com/scaleway/scaleway-cli/pull/6390)
- **alias**: creating an alias on a fresh config (`scw alias create ...`) could **panic on startup** because the in-memory alias map wasn't initialized. It now creates the map lazily. [#6392](https://github.com/scaleway/scaleway-cli/pull/6392)
- **core (docs)**: arguments containing a literal `|` **broke the Markdown argument tables** in generated docs by being read as column separators. Pipes are now escaped as `\|`. [#6359](https://github.com/scaleway/scaleway-cli/pull/6359)
- **instance**: `scw instance server-type` exposed a `list` verb for a **single-record fetch**, mislabeled for `ListServerCompatibleTypes`. The verb is now `get-compatible-types` on the server resource, so the command does what its name says. [#6474](https://github.com/scaleway/scaleway-cli/pull/6474)
- **search**: resource type value renamed `ddl_datalab` → `datalab` (see [Breaking changes](#breaking-changes-and-migrations)). [#6371](https://github.com/scaleway/scaleway-cli/pull/6371)
